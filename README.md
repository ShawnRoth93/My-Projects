# Craps Game

This is a simple Craps game implemented in Python using the Tkinter library for the GUI.

## Installation
- Ensure you have Python installed (with Tkinter included).
- Open the project in VS Code.

## Usage
- Open the terminal in VS Code.
- Run the command `CrapsGame.py`

## Code Overview
The project includes:
- **CrapsGame Class**: Handles the GUI and game logic.
- **roll_dice Function**: Simulates rolling two dice.
- **Main Block**: Initializes the Tkinter window and starts the game.
